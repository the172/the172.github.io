Wonchul Kim personal website

Main files:
- index.html
- assets/wonchul-kim-profile.jpg (original supplied profile photo; not retouched)
- assets/articles.js (weekly-updated latest article list)
- assets/Bio_Wonchul_Kim.docx

Article update workflow:
1. Search: Kim wonchul site:english.hani.co.kr
2. Confirm byline is Kim Won-chul / Wonchul Kim.
3. Add new items to assets/articles.js, newest first.
4. Keep the latest 6-9 items.
5. Publish the changed articles.js file to the hosting provider/repository.

This structure deliberately isolates article updates in a small file so weekly maintenance is simple after deployment.
